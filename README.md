## Ecosystem Overview
Nexus Truth provides enterprise-grade AI training hardware at a fraction of the cost of traditional centralized cloud providers. By utilizing idle consumer and commercial GPUs, the network offers developers high-performance compute resources for just **$1.80 per hour** while directly compensating hardware providers in **NXUS** tokens.

## Core Technologies
* **The Nexus Engine:** The lightweight desktop client that securely bridges consumer hardware to the decentralized network.
* **The Ice Age Protocol:** An algorithmic thermal management system that constantly monitors GPU temperatures to ensure absolute hardware safety and longevity.
* **The Sentinel:** A military-grade zero-knowledge verification layer that encrypts proprietary AI data and cryptographically proves compute accuracy.
